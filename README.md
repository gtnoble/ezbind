# ezbind

`ezbind` is planned as an Ada command-line application that transforms an ebook PDF into a print layout for a modified DFA home-bookbinding process.

## Project status

The repository is initialized at the **B0 project-plan gate**. The draft Project Plan is in [`plan/project-plan.md`](plan/project-plan.md). Requirements analysis and implementation are intentionally blocked until the user acknowledges that plan and resolves or explicitly defers the open physical-layout decisions listed there.

## Controlled project structure

- `plan/` — project plan, configuration status, and corrective-action records
- `requirements/` — requirements and operational-concept products
- `design/` — architecture and design products
- `src/` — Ada deliverable source
- `tests/` — test plans, descriptions, fixtures, and results
- `sdfs/` — component/project development logs
- `releases/` — release and version descriptions

See the Project Plan for lifecycle, review gates, traceability, risks, and toolchain policy.
